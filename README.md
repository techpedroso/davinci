# 🔥 Prometheus

**Prometheus** is a voice-enabled conversational AI designed to explore knowledge through dialogue.

Inspired by the myth of **Prometheus**, the titan who brought fire to humanity, this project represents the idea that knowledge should be shared, explored, and continuously refined through conversation.

Prometheus listens, understands, and responds — transforming questions into learning opportunities.

---

## Core Features

* Voice input (speech-to-text)
* Conversational AI processing
* Voice output (text-to-speech)
* Context awareness
* Memory handling
* Structured project architecture

---

## 🏗️ Project Architecture

The project is structured to keep responsibilities separated and maintainable.

(on progress)

```
prometheus/
│
├── prometheus-core       # Core logic and orchestration
├── prometheus-voice      # Speech recognition and speech synthesis
├── prometheus-context    # Conversation context management
├── prometheus-memory     # Persistent memory and knowledge tracking
└── prometheus-cli        # Command-line interface
```
